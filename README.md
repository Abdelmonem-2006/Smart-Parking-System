# Smart Parking System 

An IoT-based Smart Parking System developed using ESP32, ultrasonic sensors, and a real-time Blynk dashboard for automated slot occupancy tracking.

##  Features
- Real-time monitoring of available parking slots.
- Ultrasonic sensors (HC-SR04) for object detection.
- Cloud connectivity and live mobile/web dashboard via Blynk 2.0.
